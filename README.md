# InvoiceReader.AI - Extracts specific information from investment invoices

![.NET](https://img.shields.io/badge/.NET-9.0-blue)
![C#](https://img.shields.io/badge/C%23-12.0-purple)

## ❗ The Problem
Since 2021, I've been investing a small portion of my salary in stocks every month with a long-term vision. To manage and simplify my income tax declaration, I keep a spreadsheet with all the stock purchases and sales I've made since then. Every month, I spend hours manually filling in this spreadsheet by extracting data from the invoice generated by my brokerage.
In the past, I started developing an API to automate this process, but the brokerage changed the PDF structure and the app started breaking, which demotivated me from continuing the project. With the rise of generative AI, I decided to look for a simple and definitive solution to this problem.


## 📝 Description

InvoiceReader is an API designed to receive a stock investment invoice and extract structured data from it so I can easily input it into my personal investment tracking spreadsheet. It was developed using **.NET 9** and integrates with **OpenAI**.

## 🏗️ Architecture

This project follows the principles of Clean Architecture with clear separation of concerns:


### 📂 Project Structure

```
InvoiceReader.AI/
├── 🔧 InvoiceReader.API/      # API REST
│   ├── Core/                  # Entitys
│   ├── Infrastructure/        # Repository and Integration
│   └── Controllers/           # API Endpoints
└── 📄 InvoiceReader.sln       # Solution
```


### 💰 Costs
The model that best suited my needs in terms of cost-effectiveness was **gpt-4o-mini**. At the time of this project, the pricing per 1 million tokens is shown in the image below. Each invoice from my brokerage consumes about **5,000 input tokens** and **500 output tokens**, which means I can process around **950 invoices for just $1**.

### ✅ Conclusion
Considering I only need to read **1 invoice per month**, this project would cost me **$1 over 80 years**, assuming prices remain unchanged.
