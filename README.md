## ❗ The Problem
Since 2021, I've been investing a small portion of my salary in stocks every month with a long-term vision. To manage and simplify my income tax declaration, I keep a spreadsheet with all the stock purchases and sales I've made since then. Every month, I spend hours manually filling in this spreadsheet by extracting data from the invoice generated by my brokerage.
In the past, I started developing an API to automate this process, but the brokerage changed the PDF structure and the app started breaking, which demotivated me from continuing the project. With the rise of generative AI, I decided to look for a simple and definitive solution to this problem.


## 📝 Description

InvoiceReader is an API designed to receive a stock investment invoice and extract structured data from it so I can easily input it into my personal investment tracking spreadsheet. It was developed using **.NET 9** and integrates with **OpenAI**.

## 🔧 How it Works

### ⚙️ Configuration
Create or update the `appsettings.Development.json` file with your OpenAI credentials and configuration:
```json
{
  "OpenAI": {
    "ApiKey": "sk-proj-your-api-key",
    "ResponsesAPIUrl": "https://api.openai.com/v1/responses", // Check the OpenAI API docs in case this URL changes
    "Model": "gpt-4o-mini" // gpt-4o-mini was used here, but feel free to choose the model that best fits your use case
  }
}
```
### ⌨️ Prompting
Since we expect a structured output, each field to be completed by the AI is annotated with a description using data annotations. These annotations are included in the prompt schema that is sent along with the invoice document to OpenAI. This approach helps the model understand exactly what information it should extract and how to format the output.
```csharp
public class Stock
{
    [Description("Ticker da ação. Se terminar com a letra F, remover a última letra")]
    public string Ticker { get; set; }

    [Description("Quantidade de ações. Caso seja uma compra 'c' o valor deve ser positivo, caso seja uma venda 'v' o valor deve vir negativo")]
    public int Amount { get; set; }

    [Description("Preço unitário da ação")]
    public double Price { get; set; }
}
```

### 🧾 Example 
Below is a sample invoice snippet that the API receives. The AI uses this input, along with the field descriptions, to extract structured data:
| Market  | C/V | Ticker Specification         | Amount | Price  | Total  | D/C |
|---------|-----|------------------------------|--------|--------|--------|-----|
| BOVESPA | C   | FII PMLL PAX PMLL11 CI       | 1      | 96,96  | 96,96  | D   |
| BOVESPA | V   | MARCOPOLO POMO4F PN N2       | 2      | 8,78   | 17,56  | C   |

🧠 The AI will interpret this as:

- **Buy** operation of 1 unit of **PMLL11** at R$96.96  
- **Sell** operation of 2 unit of **POMO4F**, which should be normalized to **POMO4**, at R$8.78

The expected structured response would be:

```json
[
  {
    "Ticker": "PMLL11",
    "Amount": 1,
    "Price": 96.96
  },
  {
    "Ticker": "POMO4",
    "Amount": -2,
    "Price": 8.78
  }
]
```

### 📤 Conversion

To streamline my workflow, I decided to use the **ClosedXML** library to convert the JSON output into an Excel file.  
This allows me to quickly **copy and paste the structured data** into my main investment tracking spreadsheet, saving time and reducing manual errors.
